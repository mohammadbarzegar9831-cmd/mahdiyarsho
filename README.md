# مهدیارشو | MahdiarShow

**مهدیارشو یک وب‌سایت آموزشی فارسی برای مرور احکام اجتماعی، موضوعات اعتقادی، ارتباط مؤثر و رشد فردی است.**

- **وب‌سایت:** https://mohammadbarzegar9831-cmd.github.io/mahdiyarsho/
- **مخزن GitHub:** https://github.com/mohammadbarzegar9831-cmd/mahdiyarsho

## معرفی

محتوای مهدیارشو در چهار بخش اصلی ارائه می‌شود:

- **احکام اجتماعی:** موضوعاتی مانند امر به معروف و نهی از منکر، همسایه‌داری، گناهان زبانی، احکام فضای مجازی، ارتباط با نامحرم و احکام مجالس شادی.
- **اعتقادی:** علم و حکمت الهی، مهربانی و رأفت خدا، و خواست و قدرت الهی.
- **ارتباط مؤثر:** شیوه‌های ارتباط، فن بیان، زبان بدن و تمرین‌های بهتر دیدن و توصیف‌کردن.
- **رشد فردی:** موضوعاتی مانند قدرت تمرکز و مدیریت محرک‌ها.

## امکانات

- نمایش سازگار با تلفن همراه، تبلت و رایانه
- جست‌وجوی درون‌سایتی در محتوای صفحه‌ها و یادداشت‌های جلسات
- پیشنهاد نتیجه هنگام تایپ و پشتیبانی از شکل‌های متداول نوشتن اعداد فارسی و انگلیسی
- دسترسی به موضوعات مرتبط از طریق پیوندهای داخلی
- پیمایش جلسهٔ قبل و بعد در آرشیو یادداشت‌ها
- رعایت تنظیم کاهش حرکت و پشتیبانی از پیمایش صفحه‌کلید

## اجرا و توسعه

پروژه با HTML، CSS و JavaScript نوشته شده و برای بازسازی نمایهٔ جست‌وجو به Node.js نیاز دارد.

```bash
git clone https://github.com/mohammadbarzegar9831-cmd/mahdiyarsho.git
cd mahdiyarsho
npm run build:search
```

پس از ساخت نمایه، فایل `index.html` را در مرورگر باز کن.

## زمینهٔ آموزشی

یادداشت‌های آموزشی این وب‌سایت بر پایهٔ مطالب دورهٔ مهدیارشو، ترم دوم، با تدریس سید کاظم روح‌بخش تهیه شده‌اند. مطابق توضیح ارائه‌شده در دوره، شرکت‌کنندگان می‌توانند مطالب آموخته‌شده را از همین مرحله در وب‌سایت خود منتشر کنند.
