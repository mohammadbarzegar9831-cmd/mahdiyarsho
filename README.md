# مهدیارشو | MahdiarShow

**وب‌سایت استاتیک چندصفحه‌ای برای مرور احکام اجتماعی و اندیشه‌های اعتقادی،
با طراحی تیرهٔ لوکس و انیمیشن‌های ملایم.**

🔗 مشاهده آنلاین: [https://mohammadbarzegar9831-cmd.github.io/mahdiyarsho/](https://mohammadbarzegar9831-cmd.github.io/mahdiyarsho/)

---

## معرفی

مهدیارشو یک پروژه محتوامحور است که درس‌های احکام و اندیشه را در قالب یک
وب‌سایت مدرن و راست‌چین ارائه می‌کند. محتوا در سه بخش اصلی سازمان‌دهی شده است:

- **احکام اجتماعی** — فهرست هشت موضوع: امر به معروف و نهی از منکر، همسایه‌داری،
  گناهان زبانی، فضای مجازی، کپی‌رایت، آرایش و زینت، ارتباط با نامحرم، مجالس شادی
- **اعتقادی** — سه فصل: علم و حکمت الهی، مهربانی و رافت خدا، خواست و قدرت الهی؛
  به‌همراه زیرموضوع «هدف خلقت انسان»
- **ارتباط مؤثر** — انواع ارتباط برقرار کردن و زیرموضوع «فن بیان»

## امکانات

- 🌙 تم تیرهٔ لوکس با پالت طلایی و فیروزه‌ای
- 📱 کاملاً واکنش‌گرا (موبایل، تبلت، دسکتاپ)
- 🎬 انیمیشن‌های ملایم ورود و اسکرول (سیستم reveal)
- 🔍 جست‌وجوی درون‌سایتی با نرمال‌سازی متن فارسی (`Ctrl+K`)
- 🔄 کارت نقل‌قول چرخشی در صفحه اصلی
- 🖋 فونت وزیرمتن و پشتیبانی کامل راست‌به‌چپ
- 🧩 تماماً استاتیک: بدون هیچ وابستگی، فریم‌ورک یا بیلد

## شروع سریع

### مشاهده آنلاین

لینک GitHub Pages در بالای همین صفحه را باز کنید.

### اجرای محلی

```bash
git clone https://mohammadbarzegar9831-cmd.github.io/mahdiyarsho.git
cd REPO
```

سپس فایل `index.html` را در مرورگر باز کنید.

نیازی به نصب، سرور یا بیلد نیست. فونت وزیرمتن در صورت اتصال اینترنت از
گوگل‌فونت بارگیری می‌شود و در نبود اینترنت، فونت جایگزین استفاده خواهد شد.
